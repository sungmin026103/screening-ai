SR studio VER 34 — 규칙 기반 단독 모드 (모델 없이, 편차 없이)

[배경]
적격 문헌이 2~6편뿐인 상태에서 지도학습 모델을 돌리면 지표가 실행마다 요동친다.
Include 라벨 한 편이 바뀌면 ROC-AUC가 0.85에서 0.53으로 움직이고, 임계값과 자동 제외
전체가 따라 움직인다. 원인은 모델이 불안정해서가 아니라, 몇 편 안 되는 양성 표본으로
확률을 추정하는 일 자체가 불안정하기 때문이다.

한편 앞선 실행들에서 확인된 사실: 자동 제외를 실제로 만들어낸 것은 모델이 아니라
규칙 게이트였다. 확률이 낮아서 제외된 문헌은 0편이었다. 그렇다면 모델을 빼고 규칙만으로
선별하고, 라벨 200편은 '학습 데이터'가 아니라 '규칙의 안전성 점검'으로 쓰는 편이 낫다.

[rule_only_screen()]
  - 제외는 전적으로 규칙 게이트(노출어 / 심혈관 결과어 / 동물실험어)가 결정한다.
  - 읽는 순서만 PICO 유사도로 정한다. 제외 여부에는 쓰지 않는다.
  - 초록 없는 레코드는 별도 티어로 분리해 자동 제외하지 않는다.
  - 라벨은 "규칙이 human Include를 한 편이라도 떨어뜨리는가"만 확인한다(FN 검사).
    지도학습 모드와 달리 Include 수 하한을 두지 않는다. 게이트의 근거는 "적격이려면
    반드시 등장하는 용어"라는 논리이고, 라벨은 그 논리가 깨지지 않았는지 보는 것뿐이다.
  - 폴드 분할도 확률 추정도 없으므로 실행 간 편차가 원리적으로 0이다.

[V34.1 — 읽는 순서를 색으로만 구분]
'우선 검토 / 경계 문헌'처럼 임계값으로 집단을 가르는 대신, 사람 검토 대상 안에서
PICO 유사도 순위로 상/중/하 밴드를 매겨 색으로만 표시한다.
  - 밴드는 제외 결정에 전혀 관여하지 않는다. 사람 검토 문헌은 색과 무관하게 전부 읽는다.
  - 따라서 밴드 경계가 바뀌어도 '무엇을 읽는가'는 달라지지 않는다. 임계값 불안정성이
    결과에 전파되지 않는다는 뜻이다.
  - 값 분위수 대신 순위 3등분을 쓴다. 유사도에 동점이 많으면 값 분위수는 한 밴드로 몰린다
    (실제로 35편이 전부 '상'으로 묶이는 현상이 있었다).
  - 색: 상=연초록, 중=연노랑, 하=연회색, 초록없음=노랑. 앱 화면과 엑셀 다운로드에 동일 적용.

주의: 실제 데이터에서 적격 문헌 2편 중 1편이 '하' 밴드에 있었다. 밴드는 어디부터 읽을지에만
쓰고, 읽는 범위를 줄이는 근거로는 쓸 수 없다. 화면에도 같은 경고를 표시한다.
