SR studio VER 32 — 동료심사(Q1) 대응용 검증 체계

[문제]
V31까지의 보고서는 "safe-exclude Recall 100%, FN 0"을 전면에 내세웠다. 이 숫자는
라벨한 200편 안에서만 참이다. 심사자가 묻는 것은 '아무도 읽지 않은 자동 제외 수천 편'이고,
거기에 대한 답은 Recall이 아니라 '놓쳤을 수 있는 최대 편수(상한)'다.
실제 프로젝트에서 그 상한은 401편이었던 반면 추정 전체 적격 문헌은 53편이었다.
즉 "누락 없음"이라는 주장은 통계적으로 공허한 상태였다.

[V32 변경]
1. 위험층화 감사 (audit_risk_strata / recommend_audit_sizes / audit_size_options /
   build_risk_audit_sample / summarize_audit)
   - 자동 제외 집합을 '제외 사유 × 노출어 포함 여부'로 나눈다.
   - 셀별로 Clopper-Pearson 95% 단측 상한 × 셀 크기 = 최대 누락 편수를 계산한다.
   - 목표 상한(100/50/25/10편)별로 추가로 읽어야 할 분량을 역산해 보여준다.
     목표를 하나로 강제하지 않는다 — 셀이 크면 상한을 낮추는 비용이 급격히 커지므로,
     연구자가 비용과 보고 가능한 상한을 보고 고르는 편이 정직하다.
   - 셀 내 무작위로 감사 표본을 뽑고, 판정 업로드 시 상한을 다시 계산한다.
   - 논리적 근거와 통계적 근거를 구분해 표시한다. 노출어가 아예 없어 제외된 문헌은
     PECO상 노출이 필수이므로 제목·초록 단계에서 적격 판정 자체가 불가능하다(논리).
     노출어는 있는데 결과어가 없어 제외된 셀만 표본 감사가 필요하다(통계).

2. Known-item 복구 검사 (known_item_recovery)
   이미 적격임을 아는 문헌(연구계획서 인용문헌, 선행 리뷰 포함문헌, 다른 경로로 찾은 문헌)의
   제목을 넣으면 각각이 어느 티어에 배치됐는지 보여준다. 자동 제외로 간 문헌이 한 편이라도
   있으면 그 자체가 반증이다. 통계적 상한보다 심사자 설득력이 크다.

3. 보고서 개편
   - PRISMA_Flow 시트: 스크리닝 단계 흐름 수치(자동 제외 n, 사람 검토 n, 티어별 n).
   - Audit_Design 시트: 위험층별 상한과 목표별 추가 감사 분량.
   - Methods_Text: Recall 점추정 100% 대신 단측 95% 하한을 쓰고, 감사 상한과
     reference/forward citation 확인을 문구에 포함.
   - Interpretation 시트에 보고 원칙·논리 대 통계 근거·known-item 항목 추가.
   - 비율 지표를 '93.8%' 문자열로 기록. V31에서 1.0이 엑셀에 TRUE로 보이던 문제 해결.

[권고 보고 문구]
"Recall 100%"로 쓰지 말 것. 다음 세 가지를 함께 쓴다.
  (a) validation 표본에서의 recall과 단측 95% 하한
  (b) 자동 제외 집합 감사 후의 최대 누락 상한
  (c) 포함문헌의 reference list / forward citation 확인 결과

[V32.1 수정]
1. 감사 셀 크기 계산 오류
   audit_risk_strata가 코퍼스 예측 테이블에 표본가중치를 다시 곱해, 셀 크기 합이
   코퍼스 크기를 초과했다(실제 보고서에서 셀 합 12,318편 > 코퍼스 7,630편).
   셀 크기는 실제 문헌 수로 세도록 수정. 표본가중치는 라벨 표본을 코퍼스로 환산할 때만 쓴다.
2. 요약 시트 표기
   숫자 0이 엑셀에서 FALSE로, 1.0이 TRUE로 보이던 문제. 값 열을 전부 문자열로 기록하고
   bool은 Yes/No, 정수는 천단위 구분, 비율은 % 문자열로 적는다.
3. 라벨 일관성 경고
   ROC-AUC가 0.60 미만이면 품질게이트 사유에 "모델 성능 문제이기 이전에 Include 라벨이
   서로 성격이 다른 문헌을 섞고 있는지 확인할 것"을 추가한다. 같은 PECO로 라벨했다면
   포함문헌끼리 어휘가 겹쳐야 하며, 겹치지 않는다는 것은 기준 해석이 흔들렸다는 신호다.
